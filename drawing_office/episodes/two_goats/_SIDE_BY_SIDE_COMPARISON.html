What the Commission actually decided, and why

Before any plate was generated, a written commission (commission.json) read the narration's own shape and scored three real candidates — the same judgment call a creative director would make by hand, now a repeatable pipeline stage.

Correspondence (two crops from one plate, animated into alignment) — considered, not chosen. The story's turn isn't "these two things match," it's "these two things become visibly one." Alignment implies meeting; this story needed becoming.
Threshold (the veil as the whole spine, camera never crosses it) — considered, not chosen as primary. Real and used as a bookend, but making it the spine would leave the two goats — the passage's most concrete, most quoted image — as background description only.
Echo, “The Undivided” — CHOSEN. The narration states its own device: “No single creature could hold both halves.” One plate, split-graded in code into two fates, resolving to one unified grade at the story's own turn, then a reference-chained Christ plate receives the payoff. Zero risk of the alignment failure that killed a similar idea earlier today — the split is 100% code against one source image, never two generations hoping to match.

Where the cost actually went

3 plates (veil, two goats, Christ — the Christ plate chained off the goats plate as an image reference for palette continuity, not a blind independent generation) at 2 credits each = 6 credits. Two paid animated moments — the goat driven into the wilderness, and the veil drawn open in light — at 8.75 credits each = 17.5 credits. Everything else — the split-grade, the unification cross-dissolve, the torn-veil composite, every camera move, the score placement, the SFX bed, the captions — is $0 code, reusing this project's own proven infrastructure end to end.

Honest gaps — read before calling this done

This is a first proof, not a finished production. The final audio mix peaked at -0.0 dBFS on the SFX pass — hotter than the Bethesda build's -3.8 dB margin, worth a real ear-check before this ships. The Commission's reasoning was performed by hand (by the person building the pipeline) rather than by an automated LLM planning call — the registry, guards, and primitives it would need to run unattended are built and tested, but the actual "read the narration, query the registry, write the commission" step hasn't been automated yet. And this whole pipeline has been proven on exactly one episode — real confidence comes from running it on a few more, especially ones whose shape is less obviously contested than this one.
