## 1. Purpose & scope

One visual language — **flat inked graphic-novel art, held by camera-only motion,
laid into comic-book grids with kinetic captions** — produced the same way at two
sizes:

- **Short** — 9:16, ~60s, the viral first-class product (INV-14).
- **Long** — 16:9, 6–8 min deep-dive, the research foundation (LF-INV-1); a
  sequence of comic *pages* rather than a single-topic short.

Both run the same STUDY→…→LOCK discipline (panel + red-team + fail-closed gates).
This spec adds the motion-comic-specific recipe (MC-R*), gates (MC-G*), and the
format deltas between 9:16 and 16:9.

The **Baroque-oil plate + veo3** long-form path (`_render_images_16x9.py` /
`_animate_16x9.py`) remains valid for documentary-realist episodes; it is a
SEPARATE visual line. Motion-comic episodes use THIS spec. Choose the line per
episode in the scene plan header (`style: graphic_novel | baroque`).

   ── HUMAN GATE 2 (images) ──

2d COMIC       (new) /comic      comic engine + kinetic captions (MC-R3/R4); MC-G2/G5

## 3. The LOCKED recipe — motion-comic rules (MC-R*)

Each rule is enforced by a gate (§4) or a code default. Provenance in brackets.

- **MC-R1 — Stills: BytePlus Seedream 4.5 + ref-lock.**
  Model `seedream-4-5-251128`. Ref-lock passion beats to a bare-torso reference,
  risen beats to the risen-face reference; **context / ot_echo / human_us /
  symbolic render with NO Christ ref** (face-bleed fix). Wounds on the glorified
  body are a **flat healed scar, described positively** ("healed scar flush and
  level with the skin", same skin tone) — never "open hole / red", which renders
  a red pill. BytePlus has **no negative channel**: name only end-states, never a
  noun-to-forbid. Size is the ONLY format knob (`1440x2560` short / `2560x1440`
  long). [pilot; `seedream-no-negative-channel`; `feedback-stills-biblical-period-gate`]

- **MC-R2 — Animation: Kling camera-only, invent nothing (INK_BASE).**
  HF Kling 3.0 pro, `--aspect_ratio` per format, 5s. The INK_BASE prompt keeps the
  flat ink: "finished inked panel, only the camera moves, invent nothing, no
  morph, no subject motion, no new lines." Test ONE clip before the batch. HF
  502 / no-url is transient → idempotent re-run. **This overrides INV-13 for the
  inked line: inked art → Kling camera-only (veo3 morphs ink). Baroque → veo3.**
  [pilot; refines INV-13]

- **MC-R3 — Comic assembly: distinct clip per panel, template variety.**
  Use the comic engine (`comic_engine.py` 9:16 / `landscape_engine.py` 16:9).
  Every grid panel holds a **distinct** still/clip — NEVER one still sliced into
  boxes. `full` reserved for true hero singles. Include ≥1 **cinematic epic wide**
  (dwarfing scale) to break close-up monotony. [pilot Tier-1; `feedback-cinematic-epic-stills`]

- **MC-R4 — Kinetic captions + static red Scripture bars.**
  Plain captions **cascade word-by-word** with the payload keyword in RED; the
  box snaps in. **Scripture / red-letter bars stay STATIC** (sacred anchors, not
  TikTok text) and hold the KJV verbatim + speaker + ref. Caption text is
  de-slopped (em-dash→hyphen, curly→straight). [pilot Tier-2]

- **MC-R5 — Audio: $0 score + placed SFX + the four dynamics moves.**
  Score = chain music_library Suno excerpts with a dark→grace arc landing on the
  CTA; **loudness-match** the excerpts (no section rides over the voice). SFX
  placed at true beat times ($0 sound_library, INV-18), no choir pad. Apply the
  four dynamics moves: (a) **clear a hole** — dip music+SFX to near-silence so the
  pivotal line lands in a cleared room; (b) **gated reverb** on the sacred/Scripture
  line only; (c) a **soft low bell** on the key word; (d) **thin the CTA** — ease
  DOWN to intimacy, never swell (INV-3, `feedback-cta-felt-in-bones`,
  `feedback-no-choir-pad-under-score`). Narration always sits on top. [pilot Tier-1/2]

- **MC-R6 — Motion punch on active beats only.**
  Edit-level ffmpeg zoom-snap (open tight, snap out) on the ACTIVE beats (impact /
  crowd); sacred + reflective beats keep the slow push — the contrast is what
  reads as reverent. $0, no re-render, no morph risk. [pilot Tier-2]

- **MC-R7 `[LONG]` — ≤1 paid hero per page + native-9:16 reuse.**
  Each landscape page has one **hero** cell (the single Kling-animated inked wide),
  plus cells that are **existing 9:16 clips dropped NATIVE (zero crop)** in a 9:16
  rail, or ken-burns stills ($0). Paid pages alternate with free pages so per-episode
  animation spend stays flat. [`landscape_engine.py`; `ew04-landscape-template-scope`]

- **MC-R8 — Every artifact registered for reuse.**
  Every still/clip → `asset_index.json` `fft_<slug>` with rich metadata; redo'd
  assets deleted + de-indexed (no reject pool). The reuse bank is the batch's
  economic engine (INV-19). [🔒 `global-asset-index`]

- **MC-R9 — Never animate legible script/writing.**
  Scrolls/codices render as indistinct strokes, or animate toward a non-text focal
  element (the lamb). BytePlus writes gibberish Hebrew on scrolls even when told
  "illegible"; for an OT-echo, period Hebrew is acceptable IF the camera pushes to
  a non-text subject. [INV-17; pilot scroll]

## 5. Unified scene-plan + comic-spec schema

The join key across every stage is **`slug`**. Both JSONs are already
format-agnostic; format lives in a header, not the geometry.

**`scene_plan.json`** (content source of truth — one entry per still):
`header{ format: "9:16"|"16:9", style: "graphic_novel", provider: "byteplus",
animation{model,aspect,duration}, audio_seconds }` +
`scenes[]{ index, slug, beat, t_start, t_end, subject_type
(christ_hero|christ_detail|christ_risen|context_scene|ot_echo|human_us|symbolic),
christ_ref(bool), concept, bible_ref, prompt_seed, macro_elements[], motion
(pushin|pullback|dolly|static|hold), why, reuse }`.

**`mocomic.spec.json`** (layout track — one entry per comic page/beat):
`{ format, episode, audio, beats[]{ t:[start,end], tpl, clips[]{slug, motion,
fidelity(hero|col|kb) `[LONG]`}, cap{ type(caption|redletter), text, kw |
speaker+ref } } }`.

`[LONG]` adds `fidelity` per cell (MC-R7) and a landscape `tpl` set.

## 6. Format deltas (9:16 short ↔ 16:9 long)

| Axis | Short 9:16 | Long 16:9 |
|---|---|---|
| Canvas | 1080×1920 | 1920×1080 (comic engine renders 2560×1440 → down) |
| Image size | `1440x2560` | `2560x1440` |
| Kling aspect | `9:16` | `16:9` |
| Comic engine | `comic_engine.py` | `landscape_engine.py` (hero/col/kb fidelity) |
| Template mix | vertical stacks (`two_v`, `stack_h`, `big_inset`, `quad`) | wide rails/bands (`hero_rail`, `band_of_three`, `big_inset`, native-9:16 rails) |
| Caption geometry | bottom third, 1080-wide wrap | lower band, 1920-wide wrap, larger font scale |
| Animation scope | every scene (Kling) | ≤1 hero/page (MC-R7); rest reuse/kenburns |
| Narration | ~60s, 5-beat | 6–8 min, 7-movement (M1..M7) |
| Score | 2 Suno excerpts, dark→grace | multi-segment chain (`_add_score_lf` recipe) |

**Code parameterization required (backward-compatible, default 9:16):**
`PAGE_W/PAGE_H` → params threaded through `comic_engine`/`kinetic_caption` (two
copies unified); `byteplus_seedream` SIZE param (already a function arg — only the
CLI default is portrait); `_hf_animate_short.hf_animate` gains an `aspect_ratio`
arg (today hardcoded `9:16` at line ~102). `add_music_sfx.py` is aspect-clean —
only its timestamps are episode-specific.

## 7. Cost model (motion-comic)

- **Short:** ~13 stills BytePlus (~$0.04 ea ≈ $0.5) + ~13 Kling clips (~$0.65 ea ≈
  $8.5) + audio $0 + Opus/agent LLM $0 (in-chat) ≈ **~$9–10**.
- **Long (16:9, MC-R7):** ~10–14 pages. Only the hero cell per page is paid Kling
  (~10–14 × $0.65 ≈ **$7–9**) + new landscape stills for heroes (~$0.5) + reuse
  cells $0 + score/SFX $0 ≈ **~$8–10** animation, well under the veo3 Baroque long.
  `/cost` runs `hf generate cost` pre-flight; ASK before spend (INV-20).
