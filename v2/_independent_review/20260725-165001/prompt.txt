## 0. One-paragraph summary

The narration is the clock. Its word-aligned timeline decides how many comic
PAGES a piece needs, where each page starts and ends (always on a beat
boundary), and how long each page holds on screen. Each page gets 1–4 panels
chosen by beat density; every panel is a separate, purpose-built,
full-resolution NBP still; every panel is animated individually (Kling for
action, Seedance/Hailuo for calm); panels are boomerang/loop-extended so
**no panel ever freezes** (a deterministic lint enforces this); the page is
composited with real gutters + wobbled ink borders and a virtual page camera
whose spotlight follows the narration word timings; comic text boxes
(bubbles + captions) are drawn by code INSIDE the composite pass, cell-
relative, KJV-verbatim. Pages concatenate under the narration with the
existing score/SFX/caption/landing-hold/watermark stages. Every panel clip
is banked full-res for reuse in the 16:9 long format.

```
narration.mp3 + word alignment  (existing, locked pieces only)
      │
CP-1  page_plan.json      T seconds → N pages → panels per page (beat-driven)
CP-2  panel stills        1 NBP call per panel, full res, chained anchors
      ── HUMAN GATE (stills) ──
CP-3  panel clips         Kling 3.0 (action) / Seedance-Hailuo (calm), 5s
CP-4  loop extension      boomerang/loop to page dwell — NO FREEZE (lint)
CP-5  page composite      grid_choreography: gutters, ink borders,
                          narration-timed spotlight sweep
CP-6  text layer          bubbles + captions drawn cell-relative, in-pass
      ── HUMAN GATE (pages) ──
CP-7  assembly            concat pages + narration + score/SFX/captions
                          + landing hold + watermark
      └── bank             every panel clip + still → asset index, 16:9 reuse
```

## 2. CP-1 — Page plan: the timing math

**Deterministic core (code, $0), then an LLM pass for composition only.**

1. `T` = narration duration (e.g. 59s short; 6–8 min long).
2. **Page dwell band: 8–16s, target 12s.** Below 8s a 3–4-panel page can't
   be read; above 16s even a 4-panel sweep goes stale. (Band is a starting
   hypothesis — validated only by the 12s POC pages; tune at the POC gate.)
3. `N_pages = clamp(round(T / 12), ceil(T / 16), floor(T / 8))`
   — 59s → 5 pages; 6:30 long → ~33 pages (reuse bank cuts real cost, §9).
4. **Boundaries snap to phrase ends** (the existing clause-sized phrase
   builder in `assembly_timing.py`), never mid-phrase. Each page's dwell =
   its narration span — pages are NOT uniform length.
5. **Panels per page (1–4) from beat density**, deterministic first guess:
   words-per-second and speaker changes inside the page span → 1 panel
   (landing/pivot/sacred hold), 2 (dialogue exchange), 3–4 (action/montage).
6. **Layout per page** from panel count + shot shapes, chosen from
   `grid_choreography.LAYOUTS` (`2x2`, `2v`, `2h`, `3-big-left`,
   `3-big-top`, `3-big-right`) + full-bleed single. **Variety rule: no two
   consecutive pages share a layout; at least one full-bleed hero page per
   piece; the LAST page lands on Christ** (inherits AS-G6/G7 spirit: open
   hook, close on Christ, reverence on sacred panels).
7. **LLM pass** (same discipline as scene-plan): per panel — composition,
   speaker, `animation_tier` (calm|action), bubble/caption text pulled
   verbatim from `kjv_cache`, `jesus_variant` where applicable, reuse
   candidates from the banks. Existing gates SP-G-style + self-review +
   independent audit apply; plus the CP gates in §10.

**Output — `page_plan.json` (the one contract every later stage reads):**

```json
{ "piece": "<v1 folder>", "total_s": 59.2,
  "pages": [
    { "n": 1, "t0": 0.0, "t1": 11.8, "layout": "2x2",
      "panels": [
        { "id": "p1a", "composition": "...", "speaker": "narrator",
          "animation_tier": "action", "reuse": null,
          "focus": {"t0": 0.0, "t1": 3.1},
          "text": [ {"kind": "caption", "source": "Luke 23:40",
                      "mode": "narration"} ] },
        { "id": "p1b", "...": "..." }
      ] } ] }
```

`focus` windows come from the words spoken while that panel carries the
story — the spotlight follows the narration, not a fixed 3s metronome.

## 5. CP-4 — The NO-FREEZE guarantee (the user's hard requirement)

A 5s clip must fill up to a 16s page dwell with living motion:

1. **Boomerang extension** (forward → reverse → forward…), seamless by
   construction — the project's standard static fill. **Physics gate
   applies** (`physics-motion-check`): only motion that reads correctly
   reversed (drift, mist, breathing, flicker) may boomerang; directional
   motion (walking, falling, striking) must instead **forward-loop with a
   crossfade on the clip's own low-motion tail**, or get a 10s render.
   Per-panel choice recorded in `page_plan.json`.
2. **grid_choreography freeze fix** (looping frame selection +
   `total_duration`) — already half-done (2026-07-25), must be finished and
   re-verified as part of this build, not assumed.
3. **`page_freeze_lint.py` — new deterministic $0 gate (CP-G8):** for every
   composited page mp4, per panel cell region, compute consecutive-frame
   diffs across the FULL duration; FAIL if any cell is static beyond 0.8s
   (threshold tunable; line-boil/caption cells exempt by declared type).
   This kills the Zacchaeus frozen-panel regression class permanently — a
   machine catches it, not an eye that got tired.

## 7. CP-6 — Comic text layer (in-pass, cell-relative)

The $0 POC validated the look and the rules; production moves the drawing
INSIDE the composite pass so text rides its panel exactly (no camera-drift
placement compromises):

- **Bubbles**: ivory, wobbled double ink outline, drop shadow, tail to the
  TRUE speaker's mouth (off-panel tails legitimate); Comic Sans Bold caps
  (font swappable later without pipeline change); red-letter for Christ's
  words (user-confirmed choice pending).
- **Captions**: parchment + Georgia italic for narrator/attribution frames.
- **Timing**: each element pops at its first aligned WORD's timestamp and
  persists to page end (comic pages accumulate text).
- **CP-G7 gate (deterministic where possible):** every string byte-equal to
  its `kjv_cache.json` source ($0 code check); tail-attribution and
  mouth-cover are eye checks until a Vision check exists.
- **Muted-viewing note:** bubbles carry the DIALOGUE for muted viewers; the
  burned caption layer carries only NARRATOR lines (no double-captioning a
  line that's already on-page in a bubble). This is a policy decision the
  user should confirm.

**HUMAN GATE — pages:** watch every composited page (with text) before
assembly. Exclude/re-roll is per-panel, so a bad panel never costs a page.

## 8. CP-7 — Assembly

Concat pages in order (hard cuts default; `/ink-transition` selectively when
the cut carries meaning), mux the narration, then the existing standing
stages unchanged: score (music library chain), SFX bed, serif captions for
narrator lines, **landing hold ≥3.0s (INV-26)**, **watermark (INV-27)**,
`check_landing_hold.py`, release gates. Final page = Christ landing (AS-G7
spirit) with sacred-stillness treatment.

## 9. Reuse — the 16:9 long format (designed-in, not bolted on)

- Every panel still is generated at full res and banked; every panel CLIP
  goes into the clip bank tagged (subject/pose/framing per
  `panel_variety_lint` tags + `asset_index`).
- 9:16-ish portrait panel clips drop into 16:9 grid VERTICAL cells
  near-natively (locked `vertical-panels-cross-aspect-reuse`); wide panels
  drop into 16:9 wide cells directly.
- The long format runs the SAME pipeline (CP-1 math on a 6–8 min narration,
  16:9 page canvas, horizontal-leaning layouts) with reuse-first pulling
  from the shorts' banked panels — the marginal cost of a long drops with
  every short shipped in the same visual world.
- **16:9 page generation is UNTESTED** (technique spec §10.5) — one paid
  16:9 page is part of the validation ladder (§12).
