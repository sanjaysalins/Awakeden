## 0. The problem (why today's visual stage ships bad clips)

Today's `/animate` cut-plan **already tours the elements** of a painting
("Scene contains: …face… crown of thorns… Cut to the mouth… the eyes… the tear…
No added elements"). It has the **shape** of the gallery-tour we want. But it has
**no teeth**:

1. **The element list is free prose, never verified against the actual render.**
   The cut-planner can name a "tear track" or "nailed hands" the painting may not
   actually contain — and nothing checks the finished *clip* didn't invent a faceted
   gem on a wound, garbled text, a floating head. (These exact defects shipped.)
2. **Still, edit, and assembly are built in separate silos.** A still is rendered
   into a pool; a generic cut-planner bolts motion on; the jigsaw fits clips to words
   *last*. So a still may not even be *painted to support* a clean element-tour, and
   the clip's gallery rhythm is destroyed by an arbitrary speed-up at jigsaw time.
3. **Nothing designs the visual story to the narration, in order.** Scene mix is a
   gate, not a directed sequence.

**The fix:** make the element list a **structured, verified, LOCKED contract** that
(a) is *declared* when the beat is designed, (b) is what the still is *prompted* to
contain, (c) is *reconciled against the real render by vision* and locked, (d) is the
**only** thing the edit may crop to, and (e) is what **every clip frame is checked
against**. Then design the stills **to the narration, in order**, and **reuse first**.

## 1. The new flow (narration-first, designed-in-order)

```
STAGE 2 — VISUAL (redesigned)
  A. MEASURE   narration seconds → target still/clip count (scale to length)
  B. BEAT BOARD design the visual story IN ORDER: one beat per narration phrase,
                 each tagged hero | multi-story, with intended subject + target secs
                 (gospel-pivot hero reserved as the closing bookend)
  C. REUSE-FIRST for each beat: query the catalogue (clips + stills) by concept +
                 element-fit + topical-fit. Reuse a finished clip (loose, speed-to-fit)
                 when the subject matches; else design a NEW still.
  D. DECLARE    for each NEW still: write the element list it MUST contain
                 (the contract), built to support a clean 5–7 element tour.
  E. RENDER+LOCK render the still → VISION RECONCILE (every declared element present?
                 any jarring extra? biblical-period + grounded-real + reverent?) →
                 write element_manifest.json, png_sha256-bound, LOCKED.

STAGE 2c — ANIMATE (element-gated)
  F. EDIT       build the gallery-tour cut-plan from the LOCKED manifest ONLY —
                 full → element → element → … → return → end-hold. Frozen tableau,
                 camera-only. No element absent from the manifest. No writing.
  G. RENDER+GATE render the ~10s clip → frame-by-frame ELEMENT GATE: sampled frames'
                 content ⊆ locked elements (no new object class), frozen (frame-diff),
                 no-morph. Fail-closed.

STAGE 3 — ASSEMBLY (order-aware)
  H. ASSEMBLE   lay clips in beat-board order, speed-to-fit each beat, hero bookend
                 (open on the hook clip, CLOSE on the gospel-pivot Christ). Never reuse
                 a clip twice in one cut. → /sfx → /caption.
```

The decisive change vs. today: **B–E happen before any animation, in narration order,
and produce a verified contract** instead of a free-prose pool.

## 2. Clip-count math (scale to length)

```
target_stills = round(narration_seconds / 5)        # ~1 still per 5s on screen
target_stills = clamp(target_stills, 6, 20)          # floor 6, ceiling 20
mix:  ~50% hero (single strong subject) · ~50% multi-story (3–5 sub-vignettes)
      ≥1 of each ALWAYS; the gospel-pivot hero is the closing bookend.
each still → one ~10s source clip, sped/trimmed to fill its beat (so 12 stills
pack a 60s cut with fast, intentional moments — "double it and speed up").
```

`#03 The Forsaken Cry`: 127 words ≈ ~54s → **target ≈ 11 stills** (≈ 5–6 hero,
5–6 multi-story), closing on the Christ/cross gospel landing.

## 3. The element manifest — the binding contract (NEW artifact)

One per still: `visual/<provider>/<stem>.png.manifest.json`. Extends the existing
`coherence.json` sidecar (does not replace it).

```jsonc
{
  "still_id": "03_the-cry",
  "png_sha256": "…",                       // silently re-rendering the still busts the lock
  "subject_type": "hero",                  // hero | multi-story
  "beat_index": 0,                         // its place in the narration order
  "elements": [                            // the gallery-tour targets
    {"id":"full",  "label":"the crucified Christ's face lifted to a dark sky", "region":"full",          "verified":true},
    {"id":"mouth", "label":"the open, crying mouth",                          "region":"center",        "verified":true},
    {"id":"eyes",  "label":"anguished eyes searching the dark",               "region":"upper-center",  "verified":true},
    {"id":"crown", "label":"crown of thorns on the brow",                     "region":"top",           "verified":true},
    {"id":"tear",  "label":"a tear track down the cheek",                     "region":"center-left",   "verified":true}
  ],
  "period_real": {                         // the reality/period guard, verified by vision
    "biblical_period": true,               // 1st-century, no modern faces/dress/props/buildings
    "grounded_real":   true,               // realistic oil painting, NOT surreal/fantasy/AI-glitter
    "reverent":        true,               // no horror/grotesque/NSFW tone
    "baroque_oil":     true
  },
  "declared_by": "design",                 // step D wrote the intended list
  "reconciled_by": "vision",               // step E confirmed against the real render
  "locked": true
}
```

**Contract rules (fail-closed):**
- The **edit may target ONLY `elements[].id` where `verified:true`.** Anything else is
  a CLIP-IMAGE-GROUNDED fail before render.
- The **clip frame-check** samples N frames; each frame's detected object classes must
  be ⊆ the locked element set (no new object — no gem, no extra figure, no text).
- A still cannot LOCK unless every declared element reconciled `verified:true` **and**
  all four `period_real` flags are true. Else it re-renders (or the missing element is
  cut from the tour, by explicit human call).

## 4. The beat board — the directed visual story (NEW artifact)

`visual/beat_board.json`: the narration in order, one beat per phrase, each pinned to
a still and a role. This is what makes the stills "part of the story" instead of a
jigsawed pool.

```jsonc

  "narration_seconds": 54.3,
  "target_stills": 11,
  "beats": [
    {"i":0, "phrase":"At the ninth hour Jesus cried…", "role":"hero",        "subject":"Christ's face crying out", "target_sec":5.0, "still":"03_the-cry"},
    {"i":1, "phrase":"…the words of David's psalm…",   "role":"multi-story", "subject":"David + the dark hill",     "target_sec":4.5, "still":"02_davids-psalm"},
    …
    {"i":10,"phrase":"…it is finished.",               "role":"hero-bookend","subject":"the cross at dusk (LANDING)","target_sec":5.5, "still":"NN_the-finished-cross"}
  ]
}
```

Order is preserved at assembly (carry-forward "mostly in order + hero bookend").

## 5. The element-gated edit (the gallery tour)

Carry forward the **locked Kling hard-cut recipe** (HF Kling pro, 9:16, frozen tableau,
camera-only crop-cuts, anti-melt negatives — `feedback-shorts-generative-not-ffmpeg`).
What changes: the cut-plan is **generated from the locked manifest**, not free macro prose.

- **Hero still →** 5–7 cuts: `full → element → element → … → return → end-hold`. Each
  cut crops to one locked element region. The audience is *forced* through the painting
  like a gallery. (Christ-on-cross: full → hands → feet → face → wounds → return.)
- **Multi-story still →** the cuts tour the locked sub-vignettes (each is an element).
- **Forbidden:** any element not in the manifest; any subject motion; any writing
  animation (`feedback-never-animate-writing` — design text as illegible marks or omit).

## 6. Reuse-first (loose, topical-fit, never-twice)

Before designing any new still, query the catalogue (`clip_library/` 115 clean-reusable
+ `image_library/` + hero stills). Carry forward `feedback-no-reuse-beat-match` and
`feedback-topical-fit-gate`:

- **Reuse a finished CLIP loosely** — if the subject matches the beat, drop it in and
  **speed/trim to fit** even though its motion was tuned to other words (user's call:
  cost/speed over a perfect re-time).
- A reused clip **carries its own already-locked manifest** (it was verified when made).
- **Never reuse a clip twice inside one cut.** Reuse is *across* episodes only.
- **Only topic-neutral plates travel** between unrelated episodes; story-specific clips
  (this scene's specific staging) stay home. Topical-fit gate at the select step.
- Reuse-first is the **default cost lever** — don't paint "Christ on the cross" 10×.
