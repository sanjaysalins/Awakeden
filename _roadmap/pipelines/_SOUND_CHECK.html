Today one flag from any judge kills a card. With 5 judges flagging this often, almost no card can get through.

Many flags are real (an overclaim, the wrong speaker). Many are small wording notes (for example "glory", where the Bible says "praise"). The rule treats them the same.

The choice

A. Split the flag in two — my pick
Each judge must say which kind it is:
Doctrine error (the card says something the Bible does not) → the card fails, as today.
Wording note (a word, a tone, a phrase to fix) → the card can pass, and the note must be fixed when the script is written.
Doctrine is still checked both ways, and still fails closed.
B. Keep the rule as it is
The safest, but very few ideas will ever pass.
C. Fail only if 2 or more judges flag it
Simple, but one judge's real doctrine error could slip through. I don't recommend it.
