Part 2. What a great bake-off looks like

1. A fresh episode. Not Mockers. No sunk cost. Words are locked first, so ONLY the production recipe changes.
2. Whole recipes, stacked like a ladder. Each rung adds one layer, so we see what each layer is WORTH.
R0 today's recipe (control)
R1 + new lettering, cuts every 2-3s, split panels, parallax $0
R2 + new story shape (hook, trim, end on face) $0
R3 + cast sheets + cut-in plates small
R4 + real clips at 3 peaks quote
R5 wild card: a recipe written blind by an independent Fable seat, from scratch, so I do not anchor on my own ideas.
3. A slice, not the whole film. Hook + turn + landing, about 30s. Cheaper, and judges can compare it fast.
4. Blind, shuffled, same audio. Unlabeled cuts. Judges pick the BETTER of two (pairs), not just a score. Pairs are more honest than 0-10.
5. Measured, not just opinion ($0 numbers).
shot changes per minute - longest still-hold - text objects on screen - smallest type size - face match across shots - seconds of near-still.
6. Opinion seats that SEE video frames. Fable + Opus + Sonnet artist + Sonnet viewer (as today) + Codex/Grok where they can read images. Questions: would stop, would finish, would feel, would share, looks premium, who/what/why.
7. Rule written BEFORE we look. A layer is adopted only if it gains 1.0+ points with most seats AND the gain per dollar is worth it. Otherwise it is dropped.
8. Two different episodes. One story scene, one scripture-proof piece. A win on both = real. A win on one = maybe.
9. Owner picks last, blind. You see unlabeled A/B and choose. Your pick breaks ties.
10. Real viewers, honest odds. Seats are simulated. Best: 5-10 real seed viewers watch R0 vs the winner. We report odds with error bars. Never "proven".
