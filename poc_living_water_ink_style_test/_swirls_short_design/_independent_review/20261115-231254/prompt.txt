## 1. Format and timing math (45 s)

8 units: `front, f01..f06, back`. One picture + one clip each.

```
film  = voice + 3.0 s hold      target 45.0   PASS 42.0-48.0   FAIL outside 40.0-50.0
voice                           target 42.0   PASS 39.0-45.0   FAIL outside 37.0-47.0
words = 80-88 in total          pace 2.2 words per second
estimate = words / 2.2 + 0.4 x (voiced character quotes)       must be 38.0-42.0 s
voiced character quotes: 5 at most in the film
```

The pause is counted **only before a voiced quote**, because that is all the synth adds (`--pre-quote-pause 0.4`; post-quote pause is 0). With 4-5 quotes, 80-88 words gives 38.0-42.0 s.

| Unit | Spoken line | Estimated slot (SWS-G1e, before voice money) | Measured slot (SWS-G3) | Clip to order |
|---|---|---|---|---|
| front | hook, 4-5 words | words / 2.2 + 0.3: 3.0 s or less | PASS 2.0-3.0; WARN to 3.5; FAIL under 1.8 or over 3.5 | `max(3, ceil(slot + 0.5))` |
| f01-f06 | 11-14 words (10 or 15 = WARN); at most 1 voiced quote each | words / 2.2 + 0.4 per quote: 4.5-7.5 s | PASS 5.0-7.0; WARN 4.5-5.0, 7.0-7.5; FAIL outside | `ceil(slot + 0.5)` |
| back | last line, 10 words or fewer, then the hold | words / 2.2 + 3.0: 9.0 s or less | PASS 6.0-8.5; WARN to 9.0; FAIL over | **`min(15, ceil(slot + 2.0))`** |

- Slot of unit k = its first word's start to the next unit's first word's start. Front starts at 0.0. Back ends at `duration(narration.mp3) + 3.0`. First word by 0.40 s.
- Delivered clip at least slot + 0.10 s. **No fill, ever:** no freeze, boomerang, ping-pong, speed change, zoom, crop into a panel, or insert. 1.0x, hard cuts, tail trimmed.
- **Frame-exact cuts**, 30 fps, counted from the film start: `B(k) = round(end_s(k) x 30)`; unit k has `B(k) - B(k-1)` frames; encoded with `-frames:v N` and `fps=30` stated.
- **Size:** a trim episode must declare `w=1080, h=1920` (the 720 default is refused). Kling's 1072x1928 is `scale=1080:-2` then centred `crop=1080:1920`. Never a stretch.
- **Order:** the unit order must be identical in `MANIFEST.units`, `units.json`, `unit_timing.json` and `page_plan.json` (SWS-G8t).

**SWS-G15h — the moving hold (back clip at step 6, and again on the final file).**
1. **Frozen control:** take the last used frame, hold it 3 s, encode it through the same chain. Measure its mean frame difference (frames 0.5 s apart) = the noise floor `N`.
2. Split the 3.0 s hold into **three 1 s windows**. Measure each the same way.
3. **Every window must be at least `k x N`.** `k = 3` to start; test T8 sets it on real back covers vs their frozen copies. One window under = FAIL (so motion that stops halfway fails, and a clip frozen from frame 0 fails).
4. Measured on the clip (step 6), the draft (step 7) and the **final file** (step 9).
5. Honest limits: a slow camera drift counts as motion; `k` is a guess until T8. Until T8 passes, the played-through look on page 5 is required and recorded.

- `RUN assemble --draft` -> `<name>_draft.mp4` and **`assembly_receipt.json`** `{output_sha256, unit src hashes, narration.mp3 hash, unit_timing hash}`.

## 4. Page design rules

1. Three panels set up, the hero pays off. Panels show things, not faces.
2. Panel motion is light only. At most one panel has real motion.
3. The hero has one human action by one figure in the first half, then small living motion to the last frame.
4. The figure whose line is being spoken holds still, mouth closed. The motion goes to the named `motion_carrier`.
5. 3 full figures at most. A crowd is far, small, hatched, and declared in the plan.
6. Caption above 75% height, left of the right 15%.
7. **The back cover must read as Jesus at a glance:** larger in frame, facing or three-quarter, in the series-ref clothing. It carries the last line and the hold as ONE clip with motion written to run to the last second.
8. **The motif never sits on a thing of its own colour** (no blue stroke on water or sky). Put it on dry ground, stone, cloth or paper, or lead with gold.

**Motif:** stage by unit as SWS-G6. In stills: "a brushstroke of blue ink" + one direction + thin, matte, dry-edged. Never: thread, cord, ribbon, drip, drop, bloom, flower, petal, ring, loop, pool, puddle, glow, sparkle. In clips: never named, and `ink_changed` is a hard flag.

## 5. Spend guard SWS-G0

**What it is, honestly.** It stops mistakes: a request with no recorded yes, over the cap the owner saw, with wrong settings, twice, late, or by a second session. It does **not** prove the owner said yes: the session types `approve`. The fix for that lives outside this lane (section 13, item 1). A direct call to the OpenArt generate tools goes around every guard; it is banned by rule and looked for afterwards by `RUN reconcile`.

### 5.1 Request protocol (`POC\test_the_cross\openart_bridge.py`)

Folders under `BRIDGE\`: `gen_requests_guarded\` (new; only a session that has read `POC\SWIRLS_SHORT_SERVICER.md` watches it — an old-protocol servicer never sees these requests), `gen_claimed\`, `gen_staging\`, `gen_receipts\`, `gen_responses\`, `gen_requests_guarded\cancelled\`.

1. `submit(payload)`: if `out_path` is under a `.swirls_short` marker -> guarded. No guard context -> raise, nothing written. `guard.before()` (5.3) -> the request file is written to `gen_requests_guarded\` with: `rid` (uuid4), `episode_id`, `not_after` (now + timeout), `heartbeat` path, the priced fields, the sha256 of every ref and start image, `servicer_rules`.
2. While waiting, the client touches its heartbeat file every 10 s.
3. **Stop for any reason** — timeout, error, Ctrl-C (`finally:` / `BaseException`): the client tries to **rename** the request into `cancelled\`.
   - Rename wins = the request was never claimed. Row `CANCELLED_UNCLAIMED` (the only state that can be voided).
   - Rename fails = a servicer already claimed it. Row `LATE_PENDING`. It can **not** be voided and no new request for that unit is allowed. It is settled by `RUN fetch <rid>`.
4. **Start-up sweep:** every `RUN` paid command first looks for this episode's requests whose heartbeat is older than 60 s (a killed client) and applies rule 3 to them.
5. Paid commands are started in the background by rule (the Bash tool kills a foreground command at 10 minutes).
6. A request outside a marked folder behaves exactly as today.

### 5.2 Servicer rules (`POC\SWIRLS_SHORT_SERVICER.md`, new)

0. **Claim first:** `os.replace(gen_requests_guarded\<id>.request.json, gen_claimed\<id>.<session>.json)`. If the rename fails, someone else has it: skip. Never call a generate tool without a claim.
1. Refuse if `not_after` has passed or the heartbeat is older than 60 s: move the claim to `cancelled\` and write an error reply.
2. Send exactly the request's parameters; clips with `generateSound: false`.
3. **The moment the generate tool returns, write `gen_claimed\<id>.submitted.json` with `creation_id`** — before waiting for the render.
4. When complete, download to **`gen_staging\<id>.<ext>`**, never to `out_path`.
5. **Receipt:** call `openart_creation_show(creation_id)` and save its raw result to `gen_receipts\<rid>.json`. Copy `sent_params` and `credits_spent` **from that record**. Never type them from the call, a quote, or a balance difference. A field the record does not show is written as `null`.
6. Reply (success or error) always carries `creation_id` when one exists.

### 5.3 The guard (`POC\swirls_short.py`)

- An **exclusive lock file** (`O_CREAT|O_EXCL`) is held across check + append. `rid = uuid4`.
- **Price from the payload** (mode, model, resolution, aspect, sound, duration must match a known row, else refuse):

| Payload | Price |
|---|---|
| `anim`, `kling-3-omni`, image2video, `pro`, sound off, integer 3-15 s | 35 x duration |
| `still`, `nano-banana-pro`, image2image or text2image, 2K, 9:16 | 40 |
| any other | the `--price` on the grant; else refuse |

- `before()` refuses unless: a grant covers this step (and unit); `out_path` is under this episode; provider is OpenArt; the needed look gate is recorded with matching hashes; the step is not closed; the reroll count allows it; **no open row exists in the episode, any step**; `spent + open rows x 1.10 + this price x 1.10` is within the cap.
- `after()` confirms only if: the reply names a `creation_id`; `gen_receipts\<rid>.json` exists; `sent_params` **from the record** equal the priced fields; `credits_spent` from the record is a number and at most 1.10 x price. Then the staged file is moved to `out_path` and its `output_sha256` stored. Otherwise the row is `UNRESOLVED` and the file stays in staging.
- **Open rows** (`requested`, `UNRESOLVED`, `LATE_PENDING`, `CANCELLED_UNCLAIMED`) block every paid command and count at 1.10 x price.
- Settling an open row:
  - `RUN fetch <rid>` — reads `submitted.json`, re-reads the creation record, moves the staged file (or re-downloads it, $0). No new charge.
  - `RUN confirm <rid> --receipt <dump file> ...` — OpenArt rows need a `creation_id` and a saved record dump. **A typed amount alone is refused.** If the real figure is above the row price, the step locks until a new grant.
  - `RUN confirm <rid> --void --list-dump <file>` — only for `CANCELLED_UNCLAIMED`, and only with a saved `openart_creation_list` dump covering the request's time window that shows no creation for it.
  - If OpenArt's record cannot settle it, the row stays open and the owner decides.
- If confirmed spend passes a cap, the step locks.

### 5.4 Grants and gates (`<episode>\approvals.json`, append-only)

- `RUN quote <step>` writes `_quotes\<step>.json` `{about, at_most, items, planned_rerolls, timing_sha256}`. `at_most = ceil((quote + planned rerolls) x 1.10)`.
- `RUN approve <step> --cap <Y> --unit cr|usd [--balance N] --note "<owner's words, date>"` appends a **grant** `{grant_id, step, unit_id|null, cap, renders_allowed, quote_sha256, note}`. Refused unless: `--cap` equals the quote's `at_most`; the note contains that number and a date; the note is not the same text as any `ok` note; (cr) balance is at least the cap.
- A unit grant (`--unit-id f03 --renders 1 --cap N`) **adds** renders and cap for that unit only. It never re-opens the step for other units.
- A grant dies when its quote's `timing_sha256` no longer matches, or when the step's closing gate is recorded.
- `RUN ok <gate> --note "..."` records a look with the hashes of what was looked at. Changed files void the gate.

| Step | Opens after | First-item hard stop | Closed by |
|---|---|---|---|
| `voice` | `words` | - | `voice_ear` |
| `pictures` | `voice_ear` | `northstar_look` | `stills_animatic` |
| `clips` | `stills_animatic` | `clip_test_look` (after the 2 test clips) | `draft_cut` |
| `score` | `draft_cut` | - | `film_final` |
| `poster` | `film_final` | - | - |

### 5.5 ElevenLabs boundary

- Only three fixed commands spend: `RUN voice`, `RUN align`, `RUN score`. The runner builds the command line; there is no free-form `paid`.
- **Price before dispatch:** voice = characters in the turns that will actually be rendered (cached turns cost 0) x the invoice rate; alignment = a small fixed line; score = seconds x rate. The rates are constants typed from the owner's invoice and **marked unverified** until the first receipt.
- One open row per command; `align` runs once per audio hash.
- `build_srt.build()` refuses a marked folder. The episode's score script refuses to run outside `RUN score`.
- Honest limit: someone can still run `per_turn_synth.py` by hand. That script is out of lane (section 13).
