# Blind test — two scripts for a 50-60 s vertical Short (Luke 19:1-10, Zacchaeus). You see no other reviewer's work.
Picture style: bold scratchy-ink comic. The channel's aim: every short lands on Jesus. The audience is worldwide, many with English as a second language, many with no Bible knowledge.
Read candidates.md and KJV.txt (both in this folder). Then, for EACH script (X and Y):
1. As a total newcomer (no Bible, English second language): can you say who / what / why after one hearing? Which line, if any, would you not understand?
2. As a Bible reader: is every quote exact KJV? Anything added, wrong, or a works-based message (giving as the price of salvation)? Any blame on a people group?
3. Hook: does the first line make you stop, and does the curiosity gap pay off? Score the first 3 seconds 0-10.
4. Overall score 0-10.
Then: which one wins, and the 3 most important line fixes for the winner (old -> new). Plain short words. Write ONLY to the output path given.
5. Length: about 150-165 words (~60 s). Name any line that could be cut.
