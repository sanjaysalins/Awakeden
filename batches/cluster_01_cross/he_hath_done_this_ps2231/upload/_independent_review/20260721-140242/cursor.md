# Independent review — cursor (OK, 95s)

## Independent adversarial review — Upload Kit: *He Hath Done This*

I checked the kit against the locked narration (`narration.md`), KJV cache (`Psalm 22:31`), and the sibling kit (`it_is_finished_john1930`). KJV quotes in YT/FB bodies are verbatim. Doctrine is broadly grace-anchored. The problems are precision, framing, and a few platform mismatches the in-engine PASS hand-waves.

---

### 1. HOOKY BUT HONEST — accuracy / bait-and-switch

**YouTube (Short) TITLE — `Jesus' Last Word`**
The chosen title is `Psalm 22's Last Line Meets Jesus' Last Word`. That presents a **gospel-wide** claim. The locked narration was revised specifically so this is **John-only** (“Luke 23:46 is chronologically after; only last in John”). The title drops that guard. A harmonization-aware viewer can reasonably read this as overclaim or clickbait.

The in-engine red-team excuses this because descriptions say “John records his final word.” **Titles are the highest-visibility field**; the correction buried in paragraph three does not fix the title.

**YouTube (Short) DESCRIPTION — opening line**
> `A psalm's last line and Jesus' last breath close on the very same note`

Same issue: “Jesus' last breath” with no “in John.” The spoken script opens with **“Jesus' last breath in John.”** Metadata is less careful than the video it describes.

**TikTok — first line**
> `A psalm's last line and Jesus' last breath close on the same note.`

Again, universal “last breath,” no Johannine scope. On TikTok the first line *is* the hook; this is where precision matters most.

**Instagram — first line**
> `Jesus' last breath: It is finished.`

Compresses away both **“John records”** and any gospel qualifier. Reads like a bare historical fact, not “John’s account of Jesus’ final word.” The red-team calls this “acceptable”; for an accuracy-sensitive piece, it’s a real honesty gap in the highest-traffic line.

**Facebook TITLE — `Two Last Words`**
> `Two Last Words, a Thousand Years Apart, One Finished Work`

This misframes the psalm side. Psalm 22:31 is **third-person prophecy about future generations** (“They shall come… that he hath done this”), not a dying man’s final utterance. The locked narration explicitly rejected treating it like David’s “last breath.” Calling both sides “last words” blurs that and oversells parallel-dying-breath drama the video does not make.

**YouTube (Long-form) DESCRIPTION**
> `the man who prayed its first line breathed its last`

Garbled. It sounds like the idiom “breathed his last” applied to the **psalm**, not Jesus. Even “non-blocking for a short unit,” this block is in the shipped artifact; a copy-paste error produces broken public copy.

**SEO honesty — YouTube tags (Short + Long)**
Tags include `messianic psalm` and (long-form) `old testament prophecy`. The piece’s own locked guard says this is **thematic resonance, NOT verbal/etymological fulfilment** and that John does **not** cite Psalm 22 here. Those tags invite searchers expecting direct prophetic prediction of “It is finished.” That’s mild tag-stuffing / expectation mismatch relative to actual content.

**Mostly PASS.** “Nothing left for you to finish, only Someone to come home to” is finished-work / grace invitation, not fear, gain-loss, or works-salvation.

No explicit “come to Jesus” verb, but Christ is named and the landing is invitation-shaped. Acceptable for this series.

### 4. Platform fit

**YouTube (Short):** Description structure is fine; verse front-loaded before fold. Title is accurate-ish but not sharp — descriptive rather than curiosity-driven (contrast sibling `The First Time the Bible Says Finished, Nothing Was Broken`, which is a stronger honest hook).

**TikTok:** Punchy first line, but accuracy issue above. Hashtag count (5) is sane. No URL — correct per platform rules.

**Facebook:** Strong opening in description; **title is the weak link** (“Two Last Words”). Hashtag set drops `#ItIsFinished` while YT/TikTok/IG keep it — inconsistent within one kit.

**Instagram:** First line works as a hook but sacrifices attribution. Ten hashtags (5–12 target) is fine. `#BibleShorts` fits format.

**YouTube (Long-form) block in a short kit:** Including a full long-form block for a **short-only** piece adds clutter and ships a known-broken sentence. Operational risk, not just prose nit-pick.

### 7. Cluster / sibling collision (UK-G6 blind spot)

Titles don’t collide with sibling `It Is Finished`. But **shared `#ItIsFinished`** across both shorts in the same cross cluster will cannibalize discovery when both are live. Facebook omitting it while other platforms keep it makes the kit internally inconsistent, not strategically differentiated.

---

### 8. Red-team self-review is too lenient

The in-engine PASS dismisses Instagram attribution loss and the long-form garble as “non-blocking,” while simultaneously praising John attribution in YT/FB bodies. **The title and mobile first lines are where attribution actually fails.** That’s a process gap, not a clean bill of health.

VERDICT: REVISE
TOP FIXES:
1. Scope every “last word / last breath” hook to **John’s gospel** (YouTube title, YT Short opening line, TikTok first line, Instagram first line) — match the locked narration guard.
2. Rewrite **Facebook title** — drop “Two Last Words”; use “last line” vs “last word” framing so Psalm 22:31 isn’t sold as a parallel dying utterance.
3. Remove or repair the **YouTube Long** sentence (`breathed its last`); soften SEO tags (`messianic psalm`, `old testament prophecy`) so metadata doesn’t promise direct verbal prophecy the video explicitly denies.
