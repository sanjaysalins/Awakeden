### HOOKY BUT HONEST — real bait-and-switch problems

**1. YouTube (Short) TITLE — legend vocabulary, not the text**
```
What Thief Folds the Face-Cloth? The Empty Tomb
```
- KJV John 20:7: **“wrapped together”**, not “folds.”
- Spoken narration in this piece: **“What thief wraps the face-cloth and lays it aside?”**
- **“Folds”** is the debunked viral “folded napkin = master is coming back” legend vocabulary. For a KJV-text-accuracy channel, this is bait-and-switch: title signals folklore SEO; the video teaches ordered grave clothes as theft-disproof, not napkin symbolism.

**2. TikTok DESCRIPTION — same offense**
```
What thief folds the face-cloth? (John 20)
```
Same verb mismatch vs narration (“wraps”) and KJV (“wrapped together”). Curiosity hook is fine only if true to the text; this one isn’t.

**3. YouTube (Short) TAGS — off-thread promise**
```
folded napkin
```
**4. YouTube (Long-form) TAGS — worse**
```
folded napkin meaning
```
These target searchers wanting the **napkin-meaning myth** the video never teaches. That is SEO dishonesty and comment-section backlash waiting to happen.

**5. Facebook TITLE — scoped context stripped; reads as false claim**
```
No Angel. No Risen Lord. Only the Linen.
```
Standalone, this sounds like a flat claim **there was no angel at the tomb** — which collides with John 20:12 (Mary sees angels) and synoptic accounts. The Facebook **description** correctly scopes it (“When Peter and John ran… no angel spoke”), but **Reel titles are what get shared as headlines**. A careful believer will call this misleading even if the caption is accurate.

**6. YouTube (Long-form 16:9) block — wrong product for this asset**
**Format: short** · video path ends in `_sfx.mp4` · piece is **9:16**. Yet the kit ships a full **“YouTube (Long-form 16:9)”** title/description/tag set. An operator pasting that block onto this file mislabels the upload (aspect ratio + framing). Platform fit failure, not just clutter.

### KJV verbatim / sourcing discipline

**7. UK-G2 failure is real and unresolved**  
Blank anchor + failed KJV gate means the kit’s **“KJV-strict”** claim in verification is not earned, regardless of manual checks in the red-team note.

**8. YouTube (Long-form) DESCRIPTION — John 20:2 quoted without attribution**
```
They have taken away the Lord out of the sepulchre, and we know not where they have laid him.
```
Wording matches KJV, but it sits **unmarked** while John 20:29 gets quotes + **(John 20:29, KJV)**. On a KJV channel, inconsistent sourcing invites “misquote” accusations even when the words are exact.

**9. John 20:29 block — PASS**  
```
"Jesus saith unto him, Thomas, because thou hast seen me, thou hast believed: blessed are they that have not seen, and yet have believed." (John 20:29, KJV)
```
Checked: verbatim KJV everywhere it appears with that attribution.

**10. KJV voice drift across platforms (not a misquote, but sloppy for this brand)**
- **YouTube (Short):** “the **cloth** that had covered his head was wrapped together…”
- **YouTube (Long-form):** “the **napkin** that had covered his head was not lying with the linen clothes, but wrapped together…”
- **Narration/KJV:** “the **napkin**, that was about his head, **not lying with the linen clothes**, but wrapped together **in a place by itself**”

Short copy softens and shortens the verse; long copy is closer. Same episode, inconsistent text fidelity.

**11. TikTok / Instagram — “wrapped apart”**
```
the face-cloth wrapped apart
```
KJV: **“wrapped together in a place by itself.”** “Apart” colloquially means separate from the linen (OK-ish), but paired with “folds” elsewhere it drifts toward legend shorthand, not John’s wording.
