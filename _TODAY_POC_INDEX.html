The style library — six named looks, plus three early experiments

Every prompt today was built from one of these named rendering recipes (they're real reusable code now — drawing_office/prompts/style_anchors.py). Six became the official library; three more were tried before that library existed and are kept here for reference, two of them flagged because they kept drifting toward photoreal instead of illustration.

The library (6)

Sketchbook Ink

code name: SKETCH

Hand-drawn ink line + watercolor wash on aged sketchbook paper, warm sepia/earth palette. The workhorse — most-used look of the whole session, zero drift issues anywhere it appeared.

Used in: The Sightline, The Third Line, The Same Fire, The Earlier Page, The Blemish Hunt, Two Goats, The Father Who Ran

Survey Plate

code name: SURVEY_PLATE

Archaeological/technical cutaway engraving, muted mineral ink-wash — slate blue-grey and faded sienna, fine linework, aged parchment. Reads as a 19th-century excavation plate.

Used in: The Far Corner, The Sounding Line

Archive Catalogue

code name: ARCHIVE

Antiquarian museum-card illustration, warm low lamplight, cross-hatched linework, sepia/slate/ochre. A 19th-century accession-catalogue engraving, drawn not photographed.

Used in: The Closed File

Scribe's Ledger

code name: LEDGER

Ruled account-book page on aged cream paper, sepia ink with rubric-red accents. Flat and drawn, never a photograph of a physical book.

Used in: The Double-Entry Page

Ancient Scroll

code name: SCROLL

Papyrus-toned ground, fine sepia linework, illuminated-manuscript register. Written specifically to fight the photoreal drift the scroll concept hit on its first pass.

Used in: The One-Take Scroll

Night Threshold

code name: NIGHT_INK

Flat night ink-wash, deep blue-grey with warm ochre "pale wash reserve" for light. No lens language, no "torchlight glow" — that exact phrase is what caused the drift the first time.

Used in: The Token

Early experiments, not yet codified

Candlelit POV

round 1, pre-library

Painterly first-person, warm candlelight against dark stone, no visible narrator body. Never revisited after round 1 — a real candidate for a proper style-library entry later.

Used in: His Sky

Long Exposure

round 1, pre-library · flagged

Real long-exposure photography look, motion-smeared ghosts around one sharp figure. Genuinely stunning, but a real departure into photoreal cinematic territory — every other style stayed illustrated.

Used in: The Blur

Relic Macro

round 1, pre-library · flagged

Museum artifact macro photography, raking side-light on a pure black void. The "museum" framing is exactly the language that later caused photoreal drift elsewhere — usable, but needs the same illustration-lock fix as Ancient Scroll got.

Used in: Take Up Thy Bed

The Drawing Office — a whole new pipeline built, then corrected

Fable designed a real production system: a "Commission" stage that reads each story's own shape and picks the right device before a single pixel is spent, a registry of 16 devices, and $0 primitives (relight, crop-zoom, path-draw) built from today's proofs. Tested on Two Goats (Leviticus 16) against the real existing production version.

70.38s · $1.18 real spend, vs. ~$20.68 recorded for the existing version
Side-by-side vs. the existing production cut

Real feedback after watching this one: too many static held frames, not enough animation — a direct miss against your own already-locked rule that every panel needs real motion. Corrected in the next build.

06

The Father Who Ran — fully animated the fix

Luke 15:20, chosen specifically because the doctrine itself is motion — "grace moves first," "Jesus is the running of God." Built on the prodigal stills from round 3. 13 of 13 shots are real animated motion. Zero static holds. Every clip eye-checked frame-by-frame against a strict test: does the world actually change, not just the framing.

62.84s · $6.75 real spend · narration only, no score/SFX/captions this pass
