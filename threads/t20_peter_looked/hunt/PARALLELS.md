# Same story told in another Gospel (hand-declared)
An ANCHOR-2 in another Gospel is allowed only if it is NOT in these ranges (a different event).

- Matthew 26:69-75 (Peter's three denials and the cock crow)
- Mark 14:66-72 (same)
- John 18:15-18 (first denial at the door)
- John 18:25-27 (second and third denials, the cock crow)
- Matthew 26:31-35 (the warning before the denials, same prediction)
- Mark 14:27-31 (same prediction)
- John 13:36-38 (same prediction)

EDIT 2026-11-21: created by hub session from the standard harmony. John 21:15-19 (the shore, "lovest thou me") is a DIFFERENT event and is allowed.
