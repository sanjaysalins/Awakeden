Zacchaeus (Luke 19:1-10) — full topic-to-finished-piece E2E test

First complete run of the pipeline on a genuinely new topic, using the pivoted comic-strip-native architecture (separate purpose-built panel stills, not native whole-page generation). Every stage below actually ran, not just planned.

Every stage, real not simulated

  1. Research — exact KJV (Luke 19:1-10), apocryphal-tradition check
  2. Narration drafted — Gospel hook-to-CTA, KJV-verbatim quotes
  3. Real audio synthesized — ElevenLabs, 3 voices (narrator/Jesus/Zacchaeus), duration-locked to 58.99s via per_turn_synth.py
  4. 3 panel stills — new separate-stills architecture, chained, one character-drift caught + fixed before animating
  5. Animated, cost-tiered — Kling on the crowd panel, cheaper Minimax Hailuo on both close-ups
  6. Assembled (Stage 3, first real build) — held-frame extension to fill each narration beat, landing hold added
  7. Score mixed — reused $0 Suno library track ("sacred_grace_rise_a"), ducked under narration
  8. Captions — WhisperX forced-alignment (167/167 words recovered) + serif_captions.py burn-in
  9. Thumbnail — reused pipeline/thumbnails.py hero-frame + compose

Real findings from actually running this, not from planning it

Narration ran long — atempo needed (1.283) came out slightly above the previously-validated safe band (1.10-1.25). Minor, not blocking, but the narration draft should be tightened next time.
Character consistency drift recurred on Zacchaeus (less-specific anchor than Jesus's) -- caught and fixed with one re-roll before spending on animation, same discipline validated on the Thief piece.
Stage 3's "held-frame extension" build approach works and passes the landing-hold gate cleanly, but is a genuinely simple v1 -- no per-beat camera movement, just holds. A real next-level version would vary the hold treatment per beat.
pipeline/thumbnails.py's blank-canvas detection false-positives on our new padded-canvas (paper-bar) output shape -- a real, minor integration gap between the new architecture and this reused tool, not a failure of either.
