## Cast / object census

- **No named human cast needed.** This narration never names Moses — it's
  phrased as God's direct action ("God put a bronze one on a pole"). Per this
  skill's own locked rule, the LORD is never shown as a human figure, so the
  raising of the pole is shown as a completed fact (the object already
  standing), never an actor mid-action. Keeps this short visually distinct
  from short #2 ("God Hung Up a Snake," which DOES quote Moses's own
  forging and should carry the Moses/forge imagery instead) and from the
  Long (which shows Moses at narrative scale across many spreads) — three
  locked scripts, three different visual emphases, not one script repeated.
- **THE BRONZE SERPENT (object)** — new for this short, no existing anchor.
  Canon: plain bronze/copper only, NEVER gold (gold = Christ's glory alone,
  confirmed doctrine from Round 9's PASS-verified proof render — gilding the
  serpent itself would visually claim the object was holy, the Nehushtan
  error of 2 Kings 18:4). Crude, primitive Ancient-Near-Eastern casting —
  avoid a smooth spiral reading as a medical caduceus. On a plain wood pole.
  First approved render (s02) becomes the chained reference for every later
  appearance (multi-pose identity lock, SKILL.md sec.2) — no separate
  anchor-only spend.
- Generic unnamed Israelite figures (crowd/individual) — no cast sheet
  needed, not recurring/named.
