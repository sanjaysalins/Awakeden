# THE SERPENT -- world/creature canon sheet (Seed of the Woman)

Built 2026-08-07. The episode's one big new anchor (~18 appearances,
`world/serpent_ref.png`) -- flagged as a real gap by the independent-
review panel (2026-08-07), which also caught three planned devices
(`hunt_and_lock`, Thread Device progressive draw-on, wash-creep converge)
overclaiming what the actual code does; this sheet locks the CREATURE
itself so identity doesn't drift across 18 independently-generated stills,
the same failure class as face drift on a named human character.

## Doctrine (the reasoning, not just the rule)

This project's own standing doctrine: never render Satan sympathetically
or cartoonishly. Genesis 3's serpent is a real creature under real,
specific judgment (Gen 3:14: "cursed above all cattle... upon thy belly
shalt thou go"). Serpent = Satan is stated where the CANON states it (Rev
12:9, on this episode's own naming page, M4) -- never painted back into
the Eden frames themselves, per this narration's own panel-locked
constraint. The Eden-scene serpent is drawn as the Genesis creature; the
later identification is a separate, later, textually-grounded claim.

## Locked treatment rules (apply to EVERY serpent-focus frame)

1. **A real creature, plainly drawn** -- no dragon fantasy, no wings, no
   expressive face, no anthropomorphic posture. Loose graphite-and-ink,
   exactly like every other living thing in this style, nothing more
   elaborate.
2. **The camera looks DOWN on it, always** -- the deliberate inverse of
   this project's own Bowed Camera rule (the lens kneels at glory beats;
   it never kneels to the enemy). The one framing exception is s48's
   ground-level heel-strike frame, which is heel-focused, not
   serpent-focused, and the serpent is mid-judgment even there.
3. **Ink-blue judgment register always; NEVER gold, never a warm
   palette.** Gold stays Christ's glory only, per this project's own
   locked palette theology -- the serpent, the curse, and the desk never
   borrow it.
4. **Posture tracks the curse, in this exact order:** among branches only
   in PRE-curse frames (before Gen 3:14 is spoken); belly-to-ground, low
   in the frame, in every frame from the curse verse onward. This is not
   a style choice -- it's the verse's own stated judgment.
5. **No charm shots** -- never a full-frame face close-up, never eye
   contact with the viewer.
6. **The beaten enemy = the SHED SKIN, never a fought-and-defeated
   pose.** An empty cast skin, hollow, in the dust -- victory shown
   without gore and without staging the enemy as a fought equal. The
   head-crush itself is NEVER an impact frame: freeze the instant
   BEFORE the strike, or show its consequence (a shadow, an absence),
   never the blow itself. The narration's own theology (the cross IS the
   crushing blow) should do the visual work, not a literal strike image.

## Canon description (paste VERBATIM into every prompt that shows the serpent)

> A real serpent, plainly drawn in loose graphite-and-ink linework matching this style's own hand -- no dragon fantasy, no wings, no expressive or anthropomorphic face, no upright posture, no charm. Ink-blue-toned scales, cool judgment coloring, never gold, never warm. [Before the curse:] coiled low among tree branches or roots, still and watching. [From the curse onward:] belly flat to the ground, low in the frame, moving or resting on its underside only -- no coiling upward, no rearing.

## Usage
Chain the anchor via --image + append: "the SAME serpent as the reference
image -- identical coloring and form." Given far more pose variance than
a human character (branch-coiled, belly-flat, shadow-only, shed-skin) plus
~18 appearances, apply the SAME multi-pose identity lock this project uses
for recurring human figures: once a pose variant is approved (e.g. the
first belly-flat curse-register frame, s18 or s19), chain it as a second
reference for every later frame using that same pose family, not just the
single anchor image alone.
